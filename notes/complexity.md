# Algorithm complexity notes

| Operation | Typical cost |
| --- | --- |
| Index a list | O(1) |
| Sequential search | O(n) |
| Sort arbitrary list | O(n log n) |
| Insert into set | Expected O(1) |
| Traverse adjacency-list graph | O(V + E) |
| BFS shortest path (unweighted) | O(V + E) |

Big-O describes scaling trends rather than exact timings. Include
constant factors, input distributions and memory constraints when comparing.
