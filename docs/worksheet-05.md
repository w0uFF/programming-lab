# Worksheet 05 — SQL practice

Use the sample schema in sql/schema.sql and dummy rows in sql/seed.sql.

- List assignments with their course titles.
- Count submissions per assignment.
- Compute the mean numeric score for each assignment.
- Find tasks with no submissions using a LEFT JOIN.
- Explain a foreign key and a unique constraint.
- Add an index and inspect a query plan.

The database is intended for learning SQL, not for storing real student records.
