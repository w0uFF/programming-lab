# Programming foundations — study outline

A fictional eight-week study sequence for independent practice.

| Week | Focus | Deliverable |
| --- | --- | --- |
| 01 | Variables, conditions, loops | Number puzzles |
| 02 | Lists, dictionaries, sets | Data cleanup |
| 03 | Functions and decomposition | Text utilities |
| 04 | Searching and sorting | Algorithm comparison |
| 05 | Files, CSV, JSON | Data import |
| 06 | Data structures and graphs | Traversal exercises |
| 07 | Relational queries | SQLite workbook |
| 08 | Small applications and testing | Final mini-project |

This is an example learning roadmap, not an actual school's curriculum.
