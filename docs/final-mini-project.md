# Final practice exercise

Build a small command-line or offline browser application that imports
synthetic data, allows edits, calculates a summary, and exports a report.

## Evaluation rubric

| Dimension | Points |
| --- | ---: |
| Input validation | 20 |
| Readable function boundaries | 20 |
| Automated tests | 20 |
| Error handling | 15 |
| Clear help text | 15 |
| Documentation and limitations | 10 |

Work examples live under mini_projects/ and web/.
