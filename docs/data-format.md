# Sample data formats

## Scores CSV
Each row has a fabricated sample_id, assignment label, and numeric score.
The project does not store any real student information.

## Fixtures JSON
The classes fixture is a small nested JSON object used to practice
iteration, validation and schema design.

## Cryptography exercise fixture
The semester fixture uses an encrypted body and public-key seal to
illustrate integrity verification. It is treated as opaque input for
practice. Do not put secret keys or personal identifiers in this repository.
