# Weekly practice checklist

- [ ] Read the worksheet before writing code.
- [ ] Write down sample input and output.
- [ ] Implement the straightforward solution.
- [ ] Add at least two edge-case tests.
- [ ] Compare with a second approach where possible.
- [ ] Update the explanation with time and space complexity.
- [ ] Run the full test suite from the repository root.
- [ ] Record any unexpected behavior in the troubleshooting log.

## Review questions

1. Which assumptions are made about input ordering?
2. Are empty inputs valid?
3. How does the solution scale to a million elements?
4. How can a caller verify that output is deterministic?
