# Worksheet 01 — Numbers and loops

## Exercise A: Multiples

Given integers start, stop, and divisor, return all divisible values
inside the inclusive interval. Define behavior for a zero divisor.

## Exercise B: Prime numbers

Write a prime checker that stops trying divisors once their square
exceeds the candidate. Explain why 0 and 1 are not prime.

## Exercise C: Collatz sequence

Count steps to reach 1. Compare the number of steps for several
different starting values. Set an upper bound for unusual inputs.

### Optional extension

Measure the number of iterations for trial division vs. a
precomputed sieve of Eratosthenes.
